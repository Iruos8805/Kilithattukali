# Experiment E7: Emergent Tactics Catalogue and Detection

## Objective
Detect and quantify the frequency of advanced coordinated multi-agent maneuvers:
1. **Split-Guard**: Overloading a single guard's transverse line with multiple crossers.
2. **Decoy**: Feinting toward a line to displace the guard, creating a crossing gap for a teammate.
3. **Kili Bait**: Committing the Kili defender along one segment and exploiting lines it leaves unguarded.

## Running
```bash
uv run python experiments/e7_emergent_tactics/run_e7.py --innings 10 --seed 42
```
